# Portfolio Images Directory

Replace any file in this directory with your own photographs or project screenshots, keeping the same filenames (or updating the paths in `src/data/portfolioData.ts`).

## Expected Assets

- `hero-portrait.svg` -> Replace with your main cutout or studio portrait (recommended aspect ratio 4:5 or 3:4, dark background or transparent PNG).
- `about-portrait.svg` -> Replace with your vertical portrait for the About Me card (recommended aspect ratio 3:4).
- `project-1.svg` .. `project-8.svg` -> Replace with 16:10 or 16:9 screenshots of your featured projects.
